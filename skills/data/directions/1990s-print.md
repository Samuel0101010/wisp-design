# 1990s Print

Adopts the constraints and accidents of risograph printing, photocopier degradation, and DIY zine culture. Palette is limited (3 colours max) pulling from real Riso inks. Layers mis-register slightly, creating tactile colour-bleeds. Type mixed deliberately — display sans against grungy mono. Reads as printed and stapled, not designed in Figma.

## Principles
- Three colours maximum from real Riso/screenprint ink palettes.
- Layers mis-register 1-2px on colour overlays.
- Mixed typography — display sans against typewriter mono.
- Decorative noise at 5-10% opacity.
- Asymmetric layouts; grid deliberately broken.

## Typography
- Display: ABC Diatype, Druk, or condensed grotesk.
- Body: Courier, IBM Plex Mono, or typewriter mono.
- Mixed sizes within paragraphs for emphasis.
- Underlines and strikethroughs as ornament.
- All-caps liberally for headings.

## Color Palette (pick 3)
- Riso pink: `oklch(70% 0.25 0)`
- Riso blue: `oklch(40% 0.18 250)`
- Riso marigold: `oklch(78% 0.18 80)`
- Riso mint: `oklch(75% 0.12 165)`
- Paper: `oklch(95% 0.02 85)`
- Body: `oklch(20% 0 0)`
- Overlap creates a "third" colour via overprint multiply.

## Layout Rules
- Asymmetric grids; tilted elements (1-3 degrees max).
- Colour layers offset 1-2px to mimic Riso mis-registration.
- Grain/noise overlay at 5-10% opacity.
- Photography duo-toned to fit the 3-colour system.
- Margins inconsistent — the look is hand-pasted.

## Anti-Slop Boundaries
- No purple-blue gradient — colour is flat, layered, never gradient.
- No glassmorphism — Riso prints are matte and tactile.
- No modern drop shadows — "shadow" is colour mis-registration.

## NEVER
- More than 3 colours per composition.
- Smooth gradient fills.
- Sans-only typography.
- Pure-white background.
