# Paper Tactile

Treats the screen as a printed page. Palette pulls from offset-print ink: warm cream grounds, deep ink body, occasional saturated single-colour accent. Texture is implied through restraint — generous margins, considered line spacing, hairline rules — rather than literal paper-grain (which reads as kitsch).

## Principles
- Cream ground, never white.
- Serif body set for actual reading.
- Ink-saturated accents — deep red, navy, forest — never pastel.
- Generous line-height (1.7-1.8) and short measure (60-65ch).
- Edge details reference letterpress restraint.

## Typography
- Body: Source Serif Pro, Charter, Iowan Old Style, or GT Sectra at 17-18px.
- Display: same family, 1.5× size, weight 600.
- Captions: small-caps at 0.85em with +0.06em tracking.
- Drop-caps at section openers (3-line height).
- Numerals: oldstyle for prose, lining for data.

## Color Palette
- Ground: `oklch(96% 0.02 80)`
- Body: `oklch(22% 0.02 50)`
- Rule: `oklch(75% 0.02 50)`
- Accent (one): `oklch(40% 0.16 25)` deep red, `oklch(38% 0.12 250)` navy, `oklch(45% 0.10 145)` forest.
- Highlight: `oklch(92% 0.05 80)`

## Layout Rules
- Single column for prose; columns only when justified.
- Margins wider than gutters — the page should feel "set".
- Section breaks via hairline + 3rem, not just space.
- Images full-bleed or quarter-column; no rounded corners.
- Photography colour-graded warm.

## Anti-Slop Boundaries
- No literal paper-grain texture (reads as kitsch).
- No gradient text — defeats the print metaphor.
- No glassmorphism — paper has no transparency.

## NEVER
- Sans-serif body.
- Pure-white ground.
- Drop shadows.
- Decorative dividers (use rules).
